# 🌈 Do you like ~? · 3학년 영어

초등학교 **3학년** 학생들이 **`Do you like ~?` / `Yes, I do.` / `No, I don't.`** 표현을
듣고·따라 말하고, 직접 **좋아함 서베이**까지 해 볼 수 있는 학습용 웹앱입니다.
(5학년 *My summer vacation* 페이지와 같은 구성, 🌈 무지개·사탕 테마 디자인 / 3학년 수준)

## 주제(카테고리) 3가지

| 주제 | 낱말 (8개씩) |
|------|------|
| 🍎 음식·과일 | apple · banana · grapes · bread · salad · pizza · ice cream · orange *(수업에서 한 서베이)* |
| 🐶 동물 | dog · cat · duck · tiger · rabbit · monkey · elephant · lion |
| 🎨 색깔 | red · blue · yellow · green · pink · purple · black · white *(추천 주제)* |

## 기능 (탭 4개)

- 🗣️ **묻고 답하기** — 주제별 낱말 카드로 `Do you like ~?` 질문을 듣고,
  **👍 Yes, I do.** / **👎 No, I don't.** 를 눌러 대답을 따라 말해요.
- 📋 **좋아함 서베이** — 낱말마다 👍/👎 로 답하면, **내가 좋아하는 것 / 안 좋아하는 것**을
  한눈에 결과로 보여줘요. (수업에서 한 서베이 활동을 그대로!) 진행도와 결과는 저장돼요.
- 🎯 **듣고 맞히기** — 컴퓨터가 `Do you like ~?` 라고 물으면, 잘 듣고 **알맞은 그림**을 골라요. 점수·연속 기록!
- 🎤 **말하기 연습** — 마이크로 질문·대답을 말하면 **발음 정확도**를 알려줘요. (크롬 권장)

그 밖에:
- 영어 **낱말을 누르면** 뜻 풍선 + 발음
- **사진 / 그림(이모지)** 전환 버튼, 말하기 **속도 조절** 슬라이더

브라우저 내장 **Web Speech API**(음성 합성·음성 인식)를 사용하며,
서베이 결과·연습 기록은 브라우저(localStorage)에 저장됩니다.

## 사용 방법

`index.html` 을 브라우저(크롬 권장)에서 열면 됩니다. 따로 설치할 것이 없어요.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조(탭·섹션) |
| `style.css`  | 디자인·무지개 테마 |
| `data.js`    | 낱말·질문·대답·단어 뜻 데이터 |
| `app.js`     | 음성·단어 풍선·서베이·퀴즈·말하기 채점 로직 |
