# 🌈 Do you like ~? · 3학년 영어

초등학교 **3학년** 학생들이 **`Do you like ~?` / `Yes, I do.` / `No, I don't.`** 표현을
듣고·따라 말하며 익힐 수 있는 학습용 웹앱입니다.
(5학년 *My summer vacation* 페이지와 같은 구성, 🌈 무지개·사탕 테마 / 3학년 수준)

## 주제(카테고리) 3가지

| 주제 | 낱말 (8개씩) |
|------|------|
| 🍎 음식·과일 | apple · banana · grapes · bread · salad · pizza · ice cream · orange *(수업에서 한 서베이)* |
| 🐶 동물 | dog · cat · duck · tiger · rabbit · monkey · elephant · lion |
| ✏️ 학용품·물건 | pencil · pen · crayon · book · notebook · bag · ruler · scissors |

## 기능 (탭 2개)

- 🗣️ **묻고 답하기** — 주제별 낱말 카드로 `Do you like ~?` 질문을 듣고(🔊),
  **👍 Yes, I do.** / **👎 No, I don't.** 를 눌러 대답을 따라 말해요.
  카드 아래 **⭐ 연습 목록에 추가** 를 누르면 *내 문장 연습* 탭에 담겨요.
- 🎤 **내 문장 연습** — ⭐로 담은 문장을 마이크로 말하면 **발음 정확도**(정확도·최고·연습 횟수)를
  측정해 줘요. ✕ 로 목록에서 뺄 수 있어요. (크롬 권장)

그 밖에:
- 영어 **낱말을 누르면** 뜻 풍선 + 발음
- 그림은 또렷한 **이모지**로 보여주고, 말하기 **속도 조절** 슬라이더 제공
- 영문 글꼴은 **Comic Sans**(없는 기기에서는 웹폰트 **Comic Neue**)로 보여요.

브라우저 내장 **Web Speech API**(음성 합성·음성 인식)를 사용하며,
말하기 연습 기록은 브라우저(localStorage)에 저장됩니다.

## 사용 방법

`index.html` 을 브라우저(크롬 권장)에서 열면 됩니다. 따로 설치할 것이 없어요.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조(탭·섹션) |
| `style.css`  | 디자인·무지개 테마 |
| `data.js`    | 낱말·질문·대답·단어 뜻 데이터 |
| `app.js`     | 음성·단어 풍선·말하기 채점 로직 |
